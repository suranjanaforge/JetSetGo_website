# Travel Website Clone - Jet Set Go

## About the Project

This project is a frontend clone of a travel booking website, built using **HTML and CSS** to explore the design and layout of modern travel platforms.

The website features multiple sections showcasing travel and accommodation options, along with a dedicated area for selecting destinations and planning trips. The primary objective was to recreate a structured, visually appealing interface while developing a deeper understanding of CSS and its role in building responsive websites.

This project builds upon my initial experience with HTML and CSS, with a stronger emphasis on responsive user interfaces, complex layouts, styling techniques, and importing and managing visual assets.

## Features

- **Travel Booking Sections:** Dedicated sections presenting different travel and booking options.
- **Accommodation Options:** Interface sections for exploring different stay options.
- **Trip Planning Zone:** A dedicated area for initiating trip bookings and selecting destinations.
- **Location Selection Interface:** A prominent section designed around choosing a travel destination.
- **Structured Layout:** Organised content sections inspired by modern travel booking platforms.
- **Responsive UI Design:** CSS-based layout techniques to adapt the interface to different screen sizes.
- **Visual Asset Integration:** Imported images, icons, and other design assets to recreate the website's visual appearance.

*Note: This is a frontend clone created for learning purposes. Booking features and destination selection are visual interface elements unless functionality has been implemented separately.*

## Technologies Used

- **HTML5** — For structuring the website and organising its content into sections.
- **CSS3** — For layouts, styling, responsive design, typography, spacing, and visual effects.
- **Visual Assets** — Images, icons, and other resources imported to enhance the interface.

## Key Learnings

This project helped me develop a more detailed understanding of CSS and frontend implementation, particularly in the following areas:

- **Advanced CSS Styling:** Applying CSS properties to create visually consistent and well-structured webpages.
- **Responsive Web Design:** Understanding responsive layouts and adapting page elements to different screen sizes.
- **Layout Management:** Organising multiple sections and controlling spacing, alignment, and positioning.
- **Asset Import and Management:** Importing images and other resources and integrating them into the website.
- **UI Design Principles:** Working with visual hierarchy, typography, whitespace, and consistent styling.
- **Design-to-Code Implementation:** Translating the visual structure of a reference website into HTML and CSS.
- **Code Organisation:** Structuring HTML and CSS files for easier readability and maintenance.

## Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Navigate to the project directory

```bash
cd <your-project-folder>
```

### 3. Open the website

Open `index.html` in your preferred browser.

For a smoother development workflow, you can also open the project in Visual Studio Code and use the Live Server extension.
